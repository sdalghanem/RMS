# RMS - Resource Management System

نظام إدارة موارد وجمعيات مبني باستخدام Django.

## Features
- User & Role Management
- Beneficiaries Management
- Accounting & Funds Allocation
- Programs & Sub-programs
- Reports

## Tech Stack
- Django
- PostgreSQL / MySQL
- Bootstrap 5 (RTL)
